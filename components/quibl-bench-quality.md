# Bot Response Quality Evaluation

## Goal

Produce a lightweight FastAPI app, maybe resembling the final intended app, which exposes a  chat endpoint. The API produces two responses per chat message, generated by two different QUIBL pledge configs. 

An eval cycle consists of a study resulting in a set of pairwise head-to-head comparisons of bots according to some selection strategy, allowing a human evaluator to choose a preferred response. (For qualitative analysis, maybe we will also allow testers to write in/select a rationale for their selection)

Given these pairwise win rates, compute an ELO for each bot config, at the end  of the evaluation cycle, the highest rated bot wins.

[ELO uncovered - best practices](https://arxiv.org/abs/2311.17295)
